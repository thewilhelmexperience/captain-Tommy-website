# Content

Canonical editorial content for the Captain Tommy site.

This tree is the source of truth for written content.

## Sections

- `logs/` for dated runs, passages, deliveries, crossings, and timeline entries
- `stories/` for larger narrative pieces and memories
- `notes/` for shorter observations, route truths, place notes, and supporting fragments

Author in Markdown with YAML frontmatter.
Do not hand-edit generated site JSON as a substitute for content updates.
